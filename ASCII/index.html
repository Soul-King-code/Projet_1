    Conversion d'une Image en ASCII Art

    Ce script Python permet de convertir une image en une représentation ASCII art, c'est-à-dire une image "dessinée" avec des caractères. Voici une explication ligne par ligne et un résumé de ce que fait le code :

    Explication des lignes du code

    import PIL.Image

    Importe le module Image de la bibliothèque Pillow pour manipuler des images.

    img_flag = True
path = input("Enter the path to the image field : \n")

    Demande à l'utilisateur le chemin de l'image à convertir. Initialise un indicateur img_flag à True.

    try: 
    img = PIL.Image.open(path)
    img_flag = True
except: 
    print(path, "Unable to find image ");

    Tente d'ouvrir l'image à partir du chemin donné. Si le chemin est incorrect ou l'image introuvable, affiche un message d'erreur.

    width, height = img.size 
aspect_ratio = height/width

    Récupère la largeur et la hauteur de l'image et calcule le ratio d'aspect (hauteur divisée par largeur).

    new_width = 120 
new_height = aspect_ratio * new_width * 0.55 
img = img.resize((new_width, int(new_height)))

    Définit une nouvelle largeur (120 pixels), ajuste la hauteur en gardant le ratio d'aspect et redimensionne l'image.

    img = img.convert('L')

    Convertit l'image en niveaux de gris (noir et blanc).

    chars = ["@", "J", "D", "%", "*", "P", "+", "Y", "$", ",", ".", "."]

    Définit une liste de caractères à utiliser pour représenter les différents niveaux de gris (du plus foncé au plus clair).

    pixels = img.getdata()
new_pixels = [chars[pixel//25] for pixel in pixels]

    Obtient la valeur de chaque pixel et associe un caractère selon le niveau de gris (chaque pixel est divisé par 25 pour choisir le caractère).

    new_pixels = ''.join(new_pixels) 
new_pixels_count = len(new_pixels)
ascii_image = [new_pixels[index:index + new_width] for index in range(0, new_pixels_count, new_width)] 
ascii_image = "\n".join(ascii_image)

    Assemble les caractères en lignes de la largeur choisie pour reconstituer l'image en ASCII. Chaque ligne représente une ligne de pixels dans l'image.

    with open("ascii_image.txt", "w") as f:
    f.write(ascii_image)

    Enregistre l'image ASCII dans un fichier texte nommé ascii_image.txt.

    Que fait le code ?

    • Convertit une image en ASCII art en utilisant une liste de caractères pour représenter les différentes nuances de gris.
    • Demande à l'utilisateur le chemin de l'image.
    • Redimensionne l'image pour l'adapter à une largeur fixe (120).
    • Transforme chaque pixel en caractère ASCII selon sa luminosité.
    • Génère un fichier texte contenant le résultat, que vous pouvez ouvrir pour voir l'image en "dessin" constitué de caractères.

    En résumé :
    Ce script prend une image, la redimensionne, la convertit en niveaux de gris, puis la transforme en une série de caractères ASCII qui ressemblent à l'image originale. Le résultat est enregistré dans un fichier texte.
